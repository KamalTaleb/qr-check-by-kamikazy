QR Check by Kamikazy
====================

Paste a link -> get a QR code -> Download SVG (vector, for print) or PNG, or Copy.
Works offline. Nothing is sent anywhere.

INSTALL IN CHROME OR EDGE (any Windows PC)
1. Copy this whole "qr-check" folder to the PC (USB, Drive, WhatsApp zip...).
2. Chrome: open  chrome://extensions   (Edge: edge://extensions)
3. Turn on "Developer mode" (top right in Chrome, left side in Edge).
4. Click "Load unpacked" and pick the qr-check folder.
5. Click the puzzle icon in the toolbar and pin "QR Check by Kamikazy".
   Keep the folder where it is; Chrome loads it from there.

NO INSTALL (locked PC, or a PC with no Chrome)
Double-click popup.html. It opens in any browser and works the same,
apart from the "This page" button.

OPTIONS
- Colour / Background / No background (transparent)
- Error fix: use "Max" if you will put a logo in the middle
- PNG size up to 4096 px. For print, use the SVG: it scales to any size.
